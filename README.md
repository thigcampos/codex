# Codex

> [!IMPORTANT]
> This is a personal fork of [CodeEdit]. Changes here reflect my preferences and may
not align with the broader community's needs. I encourage supporting [CodeEdit], both
technically and financially.

Codex is a code editor written entirely and unapologetically for macOS. Derived from
CodeEdit, it features syntax highlighting, code completion, project find and replace,
snippets, a terminal, task running, debugging, Git integration, code review, extensions, and more.

[CodeEdit]: https://codeedit.app
